# Dawnreach

Experimental MOBA proof of concept built with Tauri, React, TypeScript and PixiJS.

## POC 0.1 goal

- Render a fixed battle arena plane.
- Render one controllable hero.
- Right-click a destination to move the hero.
- Show a movement marker, selection ring, level and health bar.
- Keep the first prototype deliberately small so the visual/animation pipeline can be validated before building combat systems.

Development starts on `poc/click-to-move`.
